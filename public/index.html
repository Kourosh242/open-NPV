قبل از شروع

چند نکتهٔ مهم

دانستن این‌ها جلوی سوءتفاهم را می‌گیرد.

چطور بدون اینترنت از ابزار استفاده کنم؟

یک بار نسخهٔ HTTPS را باز کن و منتظر پیام «نسخهٔ آفلاین آماده است» بمان. بعد می‌توانی ابزار را نصب کنی یا همان صفحه را آفلاین باز کنی. پاک کردن داده‌های سایت، حالت خصوصی یا کمبود فضای مرورگر می‌تواند کش را حذف کند.

گذرواژهٔ فایل کجا وارد می‌شود؟

اگر فایل گذرواژه داشته باشد، یک کادر روی همان فایل ظاهر می‌شود. گذرواژه فقط در حافظهٔ همین صفحه و برای باز کردن همان فایل استفاده می‌شود؛ ذخیره، لاگ یا ارسال نمی‌شود. رمز را در چت یا سایت دیگری نفرست.

چرا بعضی کانفیگ‌ها فقط JSON دارند؟

لینک اشتراک همهٔ قابلیت‌های Xray، مسیریابی، DNS یا افزونه‌ها را حمل نمی‌کند. هرجا تبدیل بدون اتلاف ممکن نباشد، لینک ناقص نمی‌سازیم و JSON کامل را نگه می‌داریم.

باز شدن فایل یعنی کانفیگ سالم است؟

نه. ابزار به سرورها وصل نمی‌شود و پینگ نمی‌گیرد. در NPVS تگ‌های AEAD بررسی می‌شوند، اما هویت سازنده مستقلاً تأیید نمی‌شود و NPVT1 اصالت‌سنجی رمزنگاری‌شده ندارد.

خروجی‌ها چقدر محرمانه‌اند؟

خیلی. لینک و JSON می‌توانند شامل UUID، رمز، آدرس سرور و کلیدهای اتصال باشند. کلیپ‌بورد و فایل دانلودشده خارج از کنترل برنامه‌اند؛ آن‌ها را فقط با افراد مورداعتماد به اشتراک بگذار.

حریم خصوصی، به‌صورت فنی

  • فایل‌ها با File API و در Web Worker پردازش می‌شوند؛ هیچ درخواست آپلودی وجود ندارد.
  • کانفیگ، گذرواژه و خروجی در localStorage، IndexedDB یا Cache API ذخیره نمی‌شوند. فقط انتخاب پوسته ذخیره می‌شود.
  • کش آفلاین فقط فایل‌های خود برنامه را نگه می‌دارد. آنالیتیکس، تبلیغات، فونت خارجی و CDN نداریم.
  • «پاک‌سازی» نتایج را حذف و پردازشگر را متوقف می‌کند. صفر کردن قطعی همهٔ کپی‌های حافظه در مرورگر قابل تضمین نیست.
  • خروجی دانلودشده و متن کپی‌شده می‌توانند محرمانه باشند؛ آن‌ها را جای مطمئن نگه دار.
  • فایل را فقط وقتی پردازش کن که مالک آن هستی یا اجازهٔ بررسی داری.

می‌توانی بعد از بار اول اینترنت را قطع کنی یا در ابزار شبکهٔ مرورگر، نبود درخواست‌های خروجی را ببینی.

کد منبع و قدردانی

Open NPV نسخهٔ ۰٫۲٫۱ — نرم‌افزار آزاد با پروانهٔ AGPL-3.0-only. سازنده: Kourosh242.

هستهٔ بازگشایی، برگردان TypeScript از پیاده‌سازی Pantegnos با ذکر نسخهٔ ثابت منبع است. الگوریتم‌های عمومی از Noble و فشرده‌سازی ZIP از fflate استفاده می‌کنند. فونت وزیرمتن با پروانهٔ SIL OFL به‌صورت محلی بارگذاری می‌شود.
